行情存储与自动清理

行情不写入 SQLite。内存按证券代码保存最新快照，新行情覆盖旧值；没有逐笔历史表。SQLite 中的账号、订单和成交记录不会因行情清理而被删除。

默认 1 小时没有接受到更新的证券会被自动清理，每 60 秒检查一次，读写缓存时也会检查；最多保存 10,000 个证券，超出时淘汰最久未更新的证券。重复或乱序推送不延长缓存保留时间。

启动前可通过环境变量 QUOTE_RETENTION_MS 和 QUOTE_MAX_SYMBOLS 调整。缓存保留时间与账号的行情有效期不同：过期行情在清理前仍可查看，使用“允许过期快照”的账号也只能使用尚未被清理的快照。

推送计数、行情及去重状态都只在本次进程内有效，重启后重置；清理后的证券再次推送将被视为新快照。“最近收到推送”不代表已连接到某个数据源，也不保证行情新鲜或订单成交。

新建仿真账号

用 SDK 驱动模拟交易

先在左侧新建并选择账号，再选择成交模式。模式与行情设置只影响新订单，已提交订单继续按提交时的配置处理。

账号模式订单如何成交
随机 / random按成交概率和延迟模拟成交，无需行情。
手工 / manual到“待成交”页决定成交价、数量、拒单或撤单。
行情 / quote由注入的行情撮合。买单参考卖一、卖单参考买一，限价单必须满足委托价格。

在项目目录执行 pip install -e . 更新 SDK。下面示例为独立演示程序，会创建一个演示账号并提交一笔模拟买单；请修改账号 ID 避免重复创建。

from qmt_sim_sdk import SimulationClient

client = SimulationClient("http://127.0.0.1:19720")
client.create_account("QUOTE_DEMO", "行情演示", initial_cash=100000)
client.set_execution_mode("QUOTE_DEMO", "quote", quote_max_age_ms=3000)

# 先挂单，再在行情程序的回调中持续推送
client.submit_order("000001.SZ", "buy", 100, "QUOTE_DEMO", price=10.30)
result = client.publish_quote(
    symbol="000001.SZ", last_price=10.23,
    bid_price=10.22, ask_price=10.23,
    bid_qty=12000, ask_qty=8000,
)
print(result["accepted"])
print(client.get_balance("QUOTE_DEMO").to_dict())

# 批量行情：client.publish_quotes([行情字典, ...])
# 查询快照：client.get_quote("000001.SZ")

最少字段：symbol 和 last_price。真实数据源建议带 ts（行情产生时间，Unix 毫秒）及买卖一价量；省略 ts 时使用服务器接收时间。价格单位为元、数量单位为股。

bid_price / ask_price 是买一 / 卖一价；bid_qty / ask_qty 是对应数量，0 表示没有可成交量。缺少盘口价时以最新价近似成交，缺少盘口量时不限制数量，不模拟真实排队。last_qty / cum_volume 暂仅保存，不驱动 POV/VWAP 成交量。

每次推送是完整快照，未提供的可选字段不会沿用旧值。重试同一行情时保留原 ts/seq；较旧时间、重复时间且没有更大 seq、同日回退的 seq 会被忽略。一个证券使用一个数据源；seq 按 UTC 日期换日后可重置。

默认行情有效期 3000 ms，缺失或过期时继续挂单。可改为在提交 / 行情更新的撮合检查时拒单，或允许使用过期快照（仍需有历史快照）。trading_status 支持 open、closed、halted；后两者暂停撮合。wait=True 超时会撤单。

同一快照的盘口量在同一账号内按订单提交顺序分配，全部使用后等待新快照；不同账号各自独立模拟。行情模式按实际成交金额和手续费复核资金与可卖持仓。当前无挂单冻结、T+1 和交易所排队模型；成交持仓可立即卖出。

顶部“行情监控”可查看最近推送、买卖一价量、完整数据及 SDK 查询示例。行情仅保存在内存，每个证券一条最新快照；默认 1 小时未更新自动清理，最多保留 10,000 个证券，不会删除 SQLite 中的订单或成交记录。

行情账号持仓使用最新价估值，行情缺失时使用成本价，过期快照会标记。服务重启后需重新推送；本版重启后挂单不会自动恢复撮合，请在停服前撤单。

行情源无需填写账号。随机与手工账号不会被行情推送触发成交。打开 API 文档查看 REST 格式：POST /api/market-data/quote、POST /api/market-data/quotes（每批 1–1000 条）。
